# Job Hunter OS browser companion

No build step: Chrome/Edge -> chrome://extensions (Edge: edge://extensions) -> Developer mode -> Load unpacked -> choose this directory. Reload the supported site, then click the extension toolbar icon. Side panel support is required. No auto-install or Web Store release is included.

See ../skills/fallback-no-mcp.md for the JSON contract and manual PDF/logging workflow. JSON only: YAML must be explicitly converted, never guessed. Exact visible labels and conventional HTML controls only; custom editors, iframes, unsupported hosts and ambiguous fields need manual handling. Profile changes are staged, never saved. Submission requires one fresh explicit owner click, safety attestations and non-dry-run eligible payload; local logs/caps/readiness cannot be verified by this extension.

No network requests, remote code, automatic upload or private answer persistence. Extraction captures visible main content, which can include personal information: redact before sharing. Normal browsers are NOT immune to anti-bot restrictions. Challenges stop automated assistance. Site terms still apply. Actual employer compatibility is unverified until tested with an authorized owner session.
